==========================================================================================================
                                    C  -->  PYTHON   SYNTAX CHEATSHEET
==========================================================================================================

 Made for: someone who knows C (NEB class 11-12 level) and is moving to Python
 Only SYNTAX is listed here. Logic stays the same, only the way you write it changes.
 Run a Python file with:   python filename.py     (or python3 filename.py)

 CONTENTS
   1.  Program structure & comments              2.  Variables & data types
   3.  Input / Output                            4.  Operators
   5.  Type casting                              6.  Conditions (if / switch)
   7.  Loops                                     8.  Functions
   9.  Arrays  ->  Lists                         10. Strings
   11. Structures  ->  Classes / Dictionaries    12. Pointers & memory
   13. File handling                             14. Math, random & library functions
   15. Error handling (new in Python)            16. Python-only extras (tuple, set, dict...)
   17. Pattern printing & common snippets        18. Full sample program (C vs Python)
   19. Big differences - quick summary

==========================================================================================================
 1. PROGRAM STRUCTURE & COMMENTS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------
 #include <stdio.h>                         | # not needed for print / input
 #include <math.h>                          | import math
 #include <stdlib.h>   (rand, exit)         | import random      /      import sys
 #include <string.h>                        | # not needed, string methods are built in
 #include <ctype.h>                         | # not needed, use  c.isalpha()  etc.
 #include <time.h>                          | import time
 int main() {                               | # no main needed, code runs top to bottom
     ...                                    | ...
     return 0;                              |
 }                                          |
                                            |
 (main is the starting point)               | def main():
                                            |     ...
                                            |
                                            | if __name__ == "__main__":
                                            |     main()
                                            |
 {  }   curly braces make a block           | :  (colon) + indentation (4 spaces) make a block
 statement ends with  ;                     | no semicolon, new line ends the statement
 a = 1; b = 2;   (same line)                | a = 1; b = 2     (allowed but avoid)
 // single line comment                     | # single line comment
 /* multi line                              | # python has no real multi-line comment
    comment */                              | # so use # on every line   or use
                                            | """ triple quotes """
                                            |
 long line continues freely                 | use  \  at line end to continue a line
 >> Python is CASE-SENSITIVE like C.  True / False / None start with capital letters.

 2. VARIABLES & DATA TYPES
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------
 int a = 5;                                 | a = 5
 float b = 3.5;                             | b = 3.5
 double c = 3.14159;                        | c = 3.14159          (float is 64-bit)
 char ch = 'A';                             | ch = 'A'              (it's a 1-letter string)
 char name[20] = "Ram";                     | name = "Ram"        (or 'Ram', both fine)
 int a, b, c;                               | a, b, c = 0, 0, 0
 int a = 0, b = 0;                          | a, b = 0, 0
 int a = b = c = 0;                         | a = b = c = 0
 const int MAX = 100;                       | MAX = 100            (CAPS = don't change it)
 #define PI 3.14159                         | PI = 3.14159
 long / short / unsigned int                | int                   (no size limit, no overflow)
 long long big = 123456789012;              | big = 123456789012
 int flag = 1;   /  0                       | flag = True   /   False
 NULL                                       | None
 int t = a; a = b; b = t;    (swap)         | a, b = b, a
 sizeof(a)                                  | type(a)      /      len(x) for size
 (no type check)                            | isinstance(a, int)
 1e5   (exponent form)                      | 1e5      or      10**5
 0x1F   (hex)    017   (octal)              | 0x1F  (hex)     0o17  (octal)   0b101  (binary)
 >> No need to declare the type in Python. The type is decided by the value you assign.
 >> a = 5 then a = "hi" is allowed. (Python is dynamically typed.)
 >> A variable must be assigned BEFORE it is used, otherwise NameError.
 >> Variable names: letters, digits, _ only; cannot start with a digit.

 3. INPUT / OUTPUT
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- OUTPUT ---
 printf("Hello\n");                         | print("Hello")        (newline is automatic)
 printf("%d", a);                           | print(a)
 printf("%d\n", a);                         | print(a)
 printf("a = %d\n", a);                     | print("a =", a)
                                            | print(f"a = {a}")     (f-string, best way)
                                            |
 printf("%d %d", a, b);                     | print(a, b)           (space added automatically)
 printf("%d,%d", a, b);                     | print(a, b, sep=",")
 printf("%d", a);   (no newline)            | print(a, end="")
 printf("%d ", a);  (space after)           | print(a, end=" ")
 printf("%f", x);                           | print(x)
 printf("%.2f", x);                         | print(f"{x:.2f}")
 printf("%5d", a);                          | print(f"{a:5d}")        (width 5, right aligned)
 printf("%-5d", a);                         | print(f"{a:<5d}")       (left aligned)
 printf("%05d", a);                         | print(f"{a:05d}")       (zero padded)
 printf("%8.2f", x);                        | print(f"{x:8.2f}")
 printf("%c", ch);                          | print(ch)
 printf("%s", name);                        | print(name)
 printf("%x", a);   %o                      | print(f"{a:x}")  or  hex(a)   oct(a)   bin(a)
 printf("%e", x);                           | print(f"{x:e}")
 printf("Name: %s Age: %d", n, a);          | print(f"Name: {n} Age: {a}")
 printf("%d%%", a);   (print %)             | print(f"{a}%")
 printf("{ }");                             | print("{ }")    but in f-string use {{ and }}
 printf("\n");   (blank line)               | print()
 puts(s);                                   | print(s)
 putchar(ch);                               | print(ch, end="")
 printf("%s\n", "=" * 10)  (n/a)            | print("=" * 10)       (repeat a string)
 printf("Hi\tHello");                       | print("Hi\tHello")     (same escape codes)
 >> Escape codes are the same:  \n  \t  \\  \"  \'  \0 (rare)

 --- INPUT ---
 scanf("%d", &a);                           | a = int(input())
 scanf("%f", &x);                           | x = float(input())
 scanf(" %c", &ch);                         | ch = input()[0]        (first character)
 scanf("%s", name);                         | name = input()
 gets(s);   /   fgets(s, n, stdin);         | s = input()            (takes the whole line)
 printf("Enter: "); scanf("%d",&a);         | a = int(input("Enter: "))
 scanf("%d %d", &a, &b);                    | a, b = map(int, input().split())
 scanf("%d %d %d", &a,&b,&c);               | a, b, c = map(int, input().split())
 scanf("%f %f", &x, &y);                    | x, y = map(float, input().split())
 for(i=0;i<n;i++) scanf("%d",&a[i]);        | a = list(map(int, input().split()))
 (n numbers, one per line)                  | a = [int(input()) for i in range(n)]
 scanf("%d", &a); getchar();                | # not needed, input() handles the newline
 >> input() ALWAYS gives a string. Convert with int() / float() yourself.

 4. OPERATORS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- ARITHMETIC ---
 a + b    a - b    a * b                    | a + b    a - b    a * b          (same)
 a / b     (int / int = int)                | a // b       (floor division, gives int)
 a / b     (float result)                   | a / b        (ALWAYS float in Python)
 a % b                                      | a % b                           (same)
 pow(a, b)                                  | a ** b      or     pow(a, b)
 sqrt(a)                                    | math.sqrt(a)      or    a ** 0.5
 a++      ++a                               | a += 1              (no ++ in Python)
 a--      --a                               | a -= 1              (no -- in Python)
 -a                                         | -a

 --- ASSIGNMENT ---
 a = 5                                      | a = 5
 a += 5   a -= 5   a *= 5                   | a += 5   a -= 5   a *= 5       (same)
 a /= 5   a %= 5                            | a /= 5   a //= 5   a %= 5   a **= 2
 a &= b   a |= b   a ^= b                   | a &= b   a |= b   a ^= b      (same)
 a <<= 1   a >>= 1                          | a <<= 1   a >>= 1               (same)

 --- RELATIONAL ---
 ==    !=    >    <    >=    <=             | ==    !=    >    <    >=    <=      (same)
 a < b && b < c                             | a < b < c               (chained comparison)

 --- LOGICAL ---
 a && b                                     | a and b
 a || b                                     | a or b
 !a                                         | not a

 --- BITWISE ---
 &    |    ^    ~    <<    >>               | &    |    ^    ~    <<    >>      (same)

 --- CONDITIONAL (ternary) ---
 max = (a > b) ? a : b;                     | max = a if a > b else b

 --- PYTHON ONLY ---
 (search with a loop)                       | x in a              x not in a   (membership)
 (compare pointers)                         | a is b              a is not b    (identity)
 >> and / or / not are WORDS in Python, not symbols.
 >> Order of work (precedence) is almost the same as C.

 (int) 3.7                                  | int(3.7)             -> 3

 6. CONDITIONS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- IF / ELSE IF / ELSE ---
 if (a > b) {                               | if a > b:
     printf("A");                           |     print("A")
 }                                          |
                                            |
 if (a > b) {                               | if a > b:
     ...                                    |     ...
 } else {                                   | else:
     ...                                    |     ...
 }                                          |
                                            |
 if (a > b) {                               | if a > b:
     ...                                    |     ...
 } else if (a == b) {                       | elif a == b:
     ...                                    |     ...
 } else {                                   | else:
     ...                                    |     ...
 }                                          |
                                            |
 if (a > b) printf("A");                    | if a > b: print("A")      (one-liner)
 if (a > 0 && b > 0) { }                    | if a > 0 and b > 0:
 if (a == 1 || a == 2) { }                  | if a == 1 or a == 2:
                                            | if a in (1, 2):      (shorter)
                                            |
 if (!(a > b)) { }                          | if not a > b:
 if (a) { }          (non-zero)             | if a:               (0, "", [], None = False)
 if (x >= 10 && x <= 20)                    | if 10 <= x <= 20:
 { }       (empty block)                    | pass

 --- NESTED IF ---
 if (a > 0) {                               | if a > 0:
     if (b > 0) {                           |     if b > 0:
         ...                                |         ...
     }                                      |
 }                                          |
                                            |

 --- SWITCH ---
 switch (ch) {                              | match ch:                 (Python 3.10 or newer)
   case 1:                                  |     case 1:
     printf("One");                         |         print("One")
     break;                                 |     case 2:
   case 2:                                  |         print("Two")
     printf("Two");                         |     case _:
     break;                                 |         print("Other")
   default:                                 |
     printf("Other");                       |
 }                                          |
                                            |
 case 1: case 2: ...  (fall through)        | case 1 | 2:                  (match either)
 case 'a': ...                              | case 'a':                    (chars are strings)
 (older Python / simple way)                | if ch == 1:
                                            |     ...
                                            | elif ch == 2:
                                            |     ...
                                            | else:
                                            |     ...
                                            |
 >> No break needed in match. Python cases do NOT fall through.
 >> default  becomes  case _:

==========================================================================================================
 7. LOOPS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- FOR LOOP  (range(start, stop, step)  ->  stop is NOT included) ---
 for (i = 0; i < n; i++)                    | for i in range(n):
 for (i = 1; i <= n; i++)                   | for i in range(1, n + 1):
 for (i = 0; i < n; i += 2)                 | for i in range(0, n, 2):
 for (i = 10; i >= 1; i--)                  | for i in range(10, 0, -1):
 for (i = n-1; i >= 0; i--)                 | for i in range(n - 1, -1, -1):
 for (i = 5; i < 20; i += 5)                | for i in range(5, 20, 5):
 for (i = 0; i < n; i++) {                  | for i in range(n):
     printf("%d", i);                       |     print(i)
 }                                          |
                                            |
 for ( ; ; )        (infinite)              | while True:
 for (i=0, j=n; i<j; i++, j--)              | i, j = 0, n
                                            | while i < j:
                                            |     ...
                                            |     i += 1
                                            |     j -= 1
                                            |

 --- LOOPING THROUGH ARRAYS / STRINGS (no index needed) ---
 for (i = 0; i < n; i++)                    | for x in a:
     printf("%d", a[i]);                    |     print(x)
                                            |
 (need index and value)                     | for i, x in enumerate(a):
                                            |     print(i, x)
                                            |
 for (i = 0; s[i] != '\0'; i++)             | for ch in s:
     printf("%c", s[i]);                    |     print(ch)
                                            |
 for (i = 0; i < strlen(s); i++)            | for i in range(len(s)):
 (two arrays together)                      | for x, y in zip(a, b):

 --- WHILE LOOP ---
 while (i < n) {                            | while i < n:
     ...                                    |     ...
     i++;                                   |     i += 1
 }                                          |
                                            |
 while (1) {                                | while True:
     ...                                    |     ...
 }                                          |
                                            |
 while (n != 0) {                           | while n != 0:
     n = n / 10;                            |     n = n // 10
 }                                          |
                                            |
 while (n > 0) { n /= 10; }                 | while n > 0:
                                            |     n //= 10
                                            |
 while (a && b) { }                         | while a and b:

 --- DO-WHILE  (Python has NO do-while) ---
 do {                                       | while True:
     ...                                    |     ...
 } while (cond);                            |     if not cond:
                                            |         break
                                            |

 --- BREAK / CONTINUE ---
 break;                                     | break
 continue;                                  | continue
 goto label;                                | (not available in Python)

 --- NESTED LOOP ---
 for (i = 1; i <= 3; i++) {                 | for i in range(1, 4):
     for (j = 1; j <= 3; j++) {             |     for j in range(1, 4):
         printf("*");                       |         print("*", end="")
     }                                      |     print()
     printf("\n");                          |
 }                                          |
                                            |

 --- PYTHON ONLY ---
 (use a flag variable)                      | for i in range(n):
                                            |     if cond:
                                            |         break
                                            | else:
                                            |     print("loop finished without break")
                                            |
 (no direct)                                | for _ in range(5):       (_ = don't need the counter)
 >> range() makes numbers from start up to (but NOT including) stop.
 >> Loop variable keeps its last value after the loop, same as C.
 >> else on a loop runs only if the loop was NOT stopped by break.

 8. FUNCTIONS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------
 int add(int a, int b) {                    | def add(a, b):
     return a + b;                          |     return a + b
 }                                          |
                                            |
 void show() {                              | def show():
     printf("Hi");                          |     print("Hi")
 }                                          |
                                            |
 void show(int n) { ... }                   | def show(n):
                                            |     ...
                                            |
 int main() { ... }                         | def main():
                                            |     ...
                                            |
 int add(int a, int b);   (prototype)       | # no prototype needed. But the function must be
                                            | # defined BEFORE the line that calls it runs.
                                            |
 result = add(2, 3);                        | result = add(2, 3)           (same)
 add(2, 3);                                 | add(2, 3)
 return;                                    | return
 return 0;                                  | return 0
 (return many values using pointers)        | def f():
                                            |     return 1, 2
                                            | x, y = f()
                                            |
 (no default arguments)                     | def f(a, b=10):            (default value)
                                            |     ...
                                            | f(5)    f(5, 20)
                                            |
 (no keyword arguments)                     | f(b=2, a=1)                (any order, by name)
 (variable no. of args, ...)                | def f(*args):               (args is a tuple)
                                            |     for x in args: ...
                                            |
 void swap(int *a, int *b)                  | # no pointers. Return the values instead:
                                            | a, b = b, a
                                            |
 void fill(int arr[], int n)                | def fill(arr):               (list passed by reference)
                                            |     arr[0] = 5               (changes the original)
                                            |
 (no one-line function)                     | sq = lambda x: x * x
                                            | sq(4)      -> 16
                                            |
 int fact(int n) {                          | def fact(n):
     if (n <= 1) return 1;                  |     if n <= 1:
     return n * fact(n - 1);                |         return 1
 }                                          |     return n * fact(n - 1)
                                            |

 --- SCOPE ---
 int g = 0;        (global, outside)        | g = 0                       (global, outside)
 void f() {                                 | def f():
     g = 5;                                 |     global g             (needed to CHANGE g)
 }                                          |     g = 5
                                            |
 static int count = 0;                      | (no static, use a global variable or class)
 (local variables live in { })              | (local variables live in the function)
 >> Python has no function overloading. The last def with the same name wins.
 >> Numbers, strings, tuples are passed 'by value' (can't change original).
 >> Lists, dicts are passed 'by reference' (function CAN change the original).

==========================================================================================================
 9. ARRAYS  ->  LISTS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- CREATE ---
 int a[5];                                  | a = [0] * 5
 int a[5] = {1, 2, 3, 4, 5};                | a = [1, 2, 3, 4, 5]
 int a[100] = {0};                          | a = [0] * 100
 char s[5] = {'a','b','c'};                 | s = ['a', 'b', 'c']
 int a[n];   (size from user)               | a = [0] * n
 (empty, will fill later)                   | a = []
 (squares of 0 to 4)                        | a = [i * i for i in range(5)]

 --- ACCESS ---
 a[0]    a[i]    a[i + 1]                   | a[0]    a[i]    a[i + 1]            (same)
 a[i] = 10;                                 | a[i] = 10
 a[n - 1]       (last element)              | a[-1]         (last)       a[-2]  (2nd last)
 (sub-array using loop)                     | a[1:4]        (index 1,2,3)
 (first 3 / from index 2)                   | a[:3]          a[2:]
 (every 2nd element)                        | a[::2]
 (reversed copy)                            | a[::-1]

 --- SIZE / OPERATIONS ---
 n = sizeof(a) / sizeof(a[0]);              | n = len(a)
 a[n++] = x;       (add at end)             | a.append(x)
 (shift elements, then place)               | a.insert(i, x)              (insert at index i)
 (shift elements left)                      | a.pop(i)        a.pop()    (last one)
 (shift elements left)                      | a.remove(x)                  (delete by value)
 (shift elements left)                      | del a[i]
 (loop to search)                           | x in a                       (True / False)
 (loop to search index)                     | a.index(x)                   (position of x)
 (loop to count)                            | a.count(x)
 (bubble sort etc.)                         | a.sort()                     (changes a)
                                            | b = sorted(a)                (new sorted list)
                                            | a.sort(reverse=True)         (descending)
                                            |
 (loop swap)                                | a.reverse()      or      a = a[::-1]
 (loop to sum)                              | sum(a)
 (loop for largest / smallest)              | max(a)            min(a)
 (loop copy)                                | b = a.copy()    or    b = a[:]
 (copy loop to join)                        | c = a + b                    (join two lists)
 (nothing)                                  | a.extend(b)                  (add all of b to a)
 (nothing)                                  | a.clear()                    (empty the list)
 (loop to print)                            | print(a)                     -> [1, 2, 3]
                                            | print(*a)                    -> 1 2 3
                                            |
 (loop to input)                            | a = list(map(int, input().split()))

 --- 2D ARRAY (list of lists) ---
 int m[3][3];                               | m = [[0] * 3 for i in range(3)]
 int m[2][3];  (2 rows, 3 cols)             | m = [[0] * 3 for i in range(2)]
 int m[2][2] = {{1,2},{3,4}};               | m = [[1, 2], [3, 4]]
 m[i][j]                                    | m[i][j]                      (same)
 m[i][j] = 5;                               | m[i][j] = 5
 rows = 3, cols = 4 (known)                 | rows = len(m)           cols = len(m[0])
 for (i=0;i<r;i++)                          | for i in range(r):
   for (j=0;j<c;j++)                        |     for j in range(c):
     printf("%d ", m[i][j]);                |         print(m[i][j], end=" ")
                                            |     print()
                                            |
 (print each row)                           | for row in m:
                                            |     print(*row)
                                            |
 (read matrix)                              | m = [list(map(int, input().split())) for i in range(r)]
 >> WARNING:  [[0] * 3] * 3  is a TRAP (all rows become the same list).
 >> Always use  [[0] * 3 for i in range(3)]  for 2D lists.
 >> Python lists can hold mixed types:  [1, "hi", 2.5]  and grow automatically.
 >> Going out of range gives IndexError (C gives garbage value).

==========================================================================================================
 10. STRINGS
==========================================================================================================
 C                                          | PYTHON
--------------------------------------------+-------------------------------------------------------------

 --- BASICS ---
 char s[20] = "hello";                      | s = "hello"
 char s[20];   gets(s);                     | s = input()
 s[0]    s[i]                               | s[0]    s[i]                    (same)
 s[strlen(s) - 1]                           | s[-1]                        (last character)
 strlen(s)                                  | len(s)
 s[i] = 'x';                                | s = s[:i] + 'x' + s[i+1:]      (strings can't be edited)
 (substring by loop)                        | s[2:5]       (index 2,3,4)    s[:3]    s[3:]

 --- STRING FUNCTIONS  (string.h) ---
 strcpy(a, b);                              | a = b
 strncpy(a, b, n);                          | a = b[:n]
 strcat(a, b);                              | a = a + b          or        a += b
 strcmp(a, b) == 0                          | a == b
 strcmp(a, b) != 0                          | a != b
 strcmp(a, b) > 0                           | a > b            (a < b   a >= b   also work)
 strrev(s);                                 | s = s[::-1]
 strupr(s);    toupper(c)                   | s = s.upper()         c.upper()
 strlwr(s);    tolower(c)                   | s = s.lower()         c.lower()
 strstr(s, "abc")   (find substring)        | "abc" in s                  (True / False)
                                            | s.find("abc")               (index, -1 if none)
                                            |
 strchr(s, 'a')                             | s.find('a')
 (loop to count a char)                     | s.count('a')
 (loop to replace)                          | s = s.replace("old", "new")
 (manual loop)                              | s.split()                    -> list of words
                                            | s.split(",")                (split at comma)
                                            |
 (manual loop)                              | " ".join(list_of_words)       (join with space)
 (manual loop)                              | s.strip()                    (remove spaces at ends)
 (manual loop)                              | s.startswith("ab")    s.endswith("yz")
 (manual loop)                              | s.title()   s.capitalize()   s.swapcase()
 sprintf(s, "%d", n);                       | s = str(n)       or       s = f"{n}"
 "abc" repeated 3 times (loop)              | "abc" * 3                   -> "abcabcabc"

 --- CHARACTER FUNCTIONS  (ctype.h) ---
 isalpha(c)                                 | c.isalpha()
 isdigit(c)                                 | c.isdigit()
 isalnum(c)                                 | c.isalnum()
 isspace(c)                                 | c.isspace()
 isupper(c)                                 | c.isupper()
 islower(c)                                 | c.islower()
 c - '0'      (digit char to int)           | int(c)
 c + 1       (next character)               | chr(ord(c) + 1)
 c - 'a'     (position in alphabet)         | ord(c) - ord('a')
 (int) c     (ASCII value)                  | ord(c)
 (char) 65                                  | chr(65)

 --- PRINT / LOOP ---

 19. BIG DIFFERENCES - QUICK SUMMARY  (read this twice!)
==========================================================================================================
 1.  NO  ;  and NO  { }.  Use  :  and indentation (4 spaces). Wrong indent = error.
 2.  NO type declaration.  a = 5  is enough.
 3.  NO  ++  or  --.   Use  a += 1   and   a -= 1.
 4.  /  always gives a float.   Use  //  for integer division.
 5.  &&  ||  !   become   and   or   not.
 6.  NO  do-while.   Use  while True:  with  if not cond: break.
 7.  NO  switch  in old Python.  Use  if / elif / else   (match in 3.10+).
 8.  for loop is  for i in range(...)  or  for x in list.  No (init; cond; step).
 9.  NO  char  type.  A character is just a string of length 1.
 10. Strings cannot be changed (immutable). s[0] = 'x' gives an error.
 11. Arrays become lists. Lists grow, shrink, and can hold mixed types.
 12. Negative index works:  a[-1]  is the last element.
 13. NO pointers, NO malloc/free.  Python handles memory by itself.
 14. NO main() needed.  Code runs from the first line down.
 15. input() gives a string, always convert:  int(input()).
 16. print() adds a newline by itself.  Use  end=""  to stop that.
 17. NULL becomes None,   1 / 0 become True / False   (capital T and F).
 18. Integers never overflow in Python (no limit like 32-bit int in C).
 19. A function must be DEFINED before the line that calls it is executed.
 20. Use  ==  to compare values, and  is  only to compare with None.
 21. range(5) = 0,1,2,3,4   (the last number is NOT included).
 22. Indentation must be consistent. Don't mix tabs and spaces.
